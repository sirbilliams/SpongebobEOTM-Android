# Changelog

## v1.0
First official release. It is the build tested on the AYN Thor.

- Chapters 1-4 play through. Music is rebuilt from source.
- Bottom-screen companion (dual-screen devices such as the AYN Thor):
  - Map page v2: painted chart, your-position marker, room inset, place preview, zoom, gamepad focus and travel.
  - Talk and Goals pages.
  - Touchpad cursor.
  - Bottom-screen taps now register.
- Automatic TV output when an external display is connected.
- Game fixes:
  - Chapter sound banks reload on chapter switch.
  - Retail path rounding and turning arcs for walking.
  - The secondary talk control.
  - Dialogue voice lookup covers all eight name spellings.
  - Multiply-blend shadows.
  - Per-actor 3D layering.
  - The HUD Main Menu button opens the game menu.
- Launcher with save export/import. The app doesn't include the game: import your own disc image (`.iso`).
